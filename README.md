# Kenneth Portfolio — macOS Desktop OS

React 19 + Vite 6 portfolio presented as a macOS-style desktop experience.

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run preview` — preview production build

## Deploy

Configured for Vercel (`vercel.json` SPA rewrite).
